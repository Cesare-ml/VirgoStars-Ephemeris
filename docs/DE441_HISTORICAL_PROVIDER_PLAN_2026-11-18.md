# Historical UT1 multipack validation plan — 2026-11-18

Extend the already existing explicit UT1/Delta-T scenario path to the existing experimental pole-based multipack provider. Require caller-supplied UT1 JD, TT−UT1, nonnegative perturbation and a nonempty bounded source label. A label is a caller assertion, not a source verification. All three samples must succeed, and the original provider's typed failure and failing sample must remain inspectable. Do not introduce an implicit UTC/local-time policy, silent model substitution, app change or astronomical algorithm in another language.

Before numerical runs compare the existing one-term TT→TDB conversion against ERFA `dtdb` at geocenter on four seasons every 25 years from astronomical 0 through 2300, and at selected modern endpoints. Compare seconds using the actual f64 output and the independently evaluated ERFA model: exploratory limit 100 microseconds, with separate reporting of single-f64 epoch rounding. ERFA is a model comparison, not a historical UTC or Delta-T measurement.

Exercise all ten local packs read-only: at the midpoint of each logical interval use explicit UT1 values near the selected epoch and nominal Delta-T values from the existing Espenak–Meeus model only as *chosen model examples*, with 60 seconds as an illustrative sensitivity perturbation (not a confidence interval). Compare all three provider outputs to the existing full-reader implementation for Sun, Moon, Mercury, Venus and the six Mars–Pluto system barycenters: diagnostic limits 1e-8 degree or degree/day and 1e-12 AU or AU/day. Test absent, corrupt, unregistered and boundary-crossing samples with typed errors; hash source, manifest and packs before and after. Compare additional sampled apparent directions to JPL Horizons Q45 in ICRF after ERFA Vondrák/full-2000A frame rotation as in #626: 1 arcsecond per longitude/latitude and 1e-9 AU distance; preserve actual requested TT, target/center and correction metadata. Both sides use DE441 and this does not validate physical historical Earth orientation, civil times or orbital truth.

After the first run found three ERFA residuals above 100 microseconds, isolate the one-term model from single-f64 JD quantization. Export the same one-term correction used by the Rust converter before adding it to TT; compare this correction to ERFA separately, and compare represented `(TDB−TT)` to that correction. These are post-hoc descriptive diagnostics with no newly chosen acceptance threshold; retain the original 100-microsecond failures unchanged.
