# DE441 integrated pack provider and emission refinement — 2026-11-18

The #601 `De441PackManager` is available in this stacked branch and implements the #630 experimental long-term state-provider trait directly. The source is imported from #601 rather than a second astronomical implementation; this is a branch-level integration of still-unmerged PR chains. Each requested TDB epoch selects its logical package. Missing, corrupt and uncovered states retain typed errors; no alternate model or physically overlapping neighbor is used silently. The model and physical/scientific limitations remain those documented in the preceding audits.

The earlier guard rejected every emission epoch within four machine-epsilon-scaled JD units of a logical boundary. The updated check uses the **actual signed** first-order sub-ULP refinement correction already computed by the light-time algorithm and compares it using nearby differences against the selected half-open logical interval. A corrected instant at the inclusive start is accepted; an instant at the exclusive end or outside is refused. This allows inward refinements near a boundary, while a genuine sub-ULP crossing still returns `UnsafeRefinementBoundary`, even when both packages exist. Supporting that case requires a separately reviewed method to evaluate the appropriate side without selecting unavailable data or assuming continuity across file/record boundaries.

The 1,000-epoch synthetic boundary regression exercised both inward acceptance and outward rejection; an earlier test that assumed every exact boundary should be rejected failed after the new behavior and was corrected to assert both cases. There were 252 solver traces that crossed logical packages. For each boundary the manager reported the correct missing-pack ID at reception, emission and the deflection-rate stencil (9/9 each); corrupt and exclusive-end cases returned typed errors. These tests exercise the **integrated manager implementation**, not a harness-local adapter. They are same-source comparisons and not an independent physical validation.
