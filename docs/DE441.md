# Classic JPL DE441 reader

The experimental Rust core reads the classic little-endian JPL DE441 binary,
including the `de441.eph` file distributed with Astrodienst's JPL files. It
does not read Astrodienst's compressed `.se1` files or NAIF SPK (`.bsp`)
kernels. Supply the data file separately; no ephemeris data is bundled.

```rust
use virgostars_ephemeris_core::de441::{Body, De441, JulianDateTdb};

let mut ephemeris = De441::open("/path/to/de441.eph")?;
let state = ephemeris.state(
    Body::Moon,
    Body::Earth,
    JulianDateTdb(2451545.0),
)?;
println!("{:?}", state.position_km);
# Ok::<(), Box<dyn std::error::Error>>(())
```

`De441::new` also accepts any `Read + Seek` input, including an in-memory
`Cursor`; `De441::open` reads file records on demand without loading the full
2.8 GB file. A caller can select any supported target and center. Dates must be
Julian dates on the **TDB** time scale, not UTC. Returned position and velocity
are geometric, in equatorial ICRF axes, in km and km/day respectively.
Outer-planet series represent system barycenters rather than planetary centers.

`coverage()` reports the inclusive interval from the binary header. The local
DE441 file inspected on 2026-11-09 covers JD -3027215.5 to 7930192.5; those
binary values take precedence over the file's human-readable title. This
reader does not convert civil time, apply light-time, aberration, deflection,
precession, nutation or topocentric corrections, or compute zodiac positions.
It is not a complete astrological ephemeris API.

## Read-only local file coverage inspector (experimental)

For a **locally supplied classic binary** DE441 file, run:

```bash
cargo run --offline --locked --example inspect_classic_de441 -- /path/to/de441.eph
```

On success, stdout is exactly two CSV lines with the format identifier and
**inclusive start/end TDB Julian dates declared by the binary header**:

```csv
format,coverage_start_jd_tdb,coverage_end_jd_tdb
classic-de441,1000,1032
```

The numbers above are from a **synthetic test file**, not an official JPL
kernel. The command checks the classic DE441 header and file length through
`De441::new`; it does **not** read/evaluate every polynomial record,
authenticate the kernel, calculate sky positions or prove agreement with
NAIF/JPL Horizons. No external data are downloaded or bundled. Missing,
short, wrong-format or inconsistent-length files fail with a nonzero exit
code and no partial CSV output. Do not run this on NAIF `.bsp` kernels.

### Optional full-record date-pair audit

The default inspector reads only the header and declared file length. To also
check **every** coefficient record's 16-byte TDB start/end date pair, opt in:

```bash
cargo run --offline --locked --example inspect_classic_de441 -- --audit-record-dates /path/to/de441.eph
```

The new `De441::audit_record_dates()` Rust method checks every expected
record start/end against the validated header's start and step, with
**inclusive overall coverage**. The command performs one seek + 16-byte
read per record and emits the same two-line coverage CSV on **stdout**,
only after the audit finishes successfully. The number of checked records is
printed to **stderr**. Invalid date pairs (including non-finite values),
truncated reads and I/O errors cause a nonzero exit with **no CSV output**.
This optional scan can be slow on large files, and does not read polynomial
coefficients or certify the file's authenticity, data provenance, numerics,
reference frame, target/center chains or scientific accuracy.

`De441::new` is intentionally unchanged and does not automatically scan all
records; existing state reads continue to check the selected record's
date pair. The original header-only invocation remains backward compatible.
Validation requires independent NAIF/JPL references and is still pending.

CLI/parser regression tests (including synthetic one-record validation):

```bash
cargo test --offline --locked --example inspect_classic_de441
```

Run `cargo test --workspace`. To exercise the external file too, set
`DE441_PATH` to its path and run `cargo test --workspace -- --ignored`.
Tests check analytical polynomials, velocities,
boundaries, Earth/Moon reconstruction, invalid files and local-file regression.
The reader rejects non-finite Chebyshev coefficients and non-finite evaluated
positions or velocities with `De441Error::InvalidFile`, rather than returning
NaN/Infinity states from damaged input records.
The regression values were produced by the earlier JavaScript prototype, so
they are not an independent scientific reference. Comparison with JPL
reference vectors is still needed before claiming numerical accuracy or
production readiness.
