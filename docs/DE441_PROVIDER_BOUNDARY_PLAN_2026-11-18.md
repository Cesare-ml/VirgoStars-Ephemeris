# Multipack long-term boundary audit — plan before execution

Build a local diagnostic executable using the unchanged `De441PackManager` source from PR #601 and the unchanged long-term experimental core from #626. The two branches are not integrated: the temporary harness copies the exact manager source into a private build directory, verifies its SHA-256, and calls it against the #626 core. It is not a production integration. Preserve the owner files and verify source, manifest and all ten slice hashes before and after.

At each of the nine internal logical boundaries, test TDB offsets −0.08, −0.02, −1 second, zero, +1 second, +0.02 and +0.08 day for the Sun, Moon, Mercury, Venus and the Mars/Jupiter/Saturn/Uranus/Neptune/Pluto system barycenters. Check selected IDs against the half-open catalog. For every case compare manager states and acceleration with the full source, and use the existing light-time solver with a callback forwarding each requested TDB epoch to the manager; compare the result with the full-source solver. Record individual reception and emission package IDs, crossing counts and errors. Predeclared component limits: 1e-6 km, 1e-6 km/day and 1e-6 km/day²; light-time vector 1e-6 km and 1e-6 km/day, emission time 1e-9 day.

Separately calculate the existing full long-term apparent six fields with the *reception-selected single file* versus the source at the same samples; limits 1e-8 degree or degree/day and 1e-12 AU or AU/day. This intentionally tests a hypothetical adapter, not a provider-backed apparent pipeline: it must also report when the emission falls in another logical package, because record-aligned slice overlap must not hide a missing installation. The frame derivative uses TT ±0.01 day within the orientation matrix, not additional provider state reads. The TDB ±0.02/0.08 samples exercise observation-side numerical-reference stencils, not the internal matrix stencil.

For each boundary, simulate a missing previous pack and missing current pack using non-existent paths in caller-owned specs without changing any real file; verify manager typed `MissingPack` at reception and emission respectively and no fallback. Include corrupt-file, out-of-range, invalid epoch and selection/cache reversal checks. Record expected failure paths rather than suppressing them. Pre/post hash all data. No external software or data committed, no activation, no claim that matching the same DE441 coefficients validates the physical orbit.

Follow-up specified after the first provider run: verify at all nine boundaries that the single reception-selected experimental file still succeeds for Pluto when the provider would reject the absent prior pack; this distinguishes physical record padding from logical installation and is a deliberate negative finding. For each body and boundary, evaluate a continuity residual across the actual floating-point epochs at ±1 second: wrapped position change minus trapezoidal average of the two output rates times the actual TDB interval. Before running this follow-up, set diagnostic residual limits of 1e-8 degree for longitude/latitude and 1e-12 AU for distance. This is a local consistency check, not proof of a physically accurate orbit or frame.

Independent follow-up fixed before acquiring new data: at each of the nine exact logical boundaries and for the same ten targets query JPL Horizons observer Q45/Q20 at the central TT epoch and ±0.02/±0.04 TT day, using the existing approximate TDB→TT conversion and actual printed TT abscissae. Rotate the apparent airless geocentric ICRF directions with ERFA Vondrák poles, J2000 bias and full 2000A nutation, as in #626. Compare positions and five-point derivatives to the source-backed long-term candidate using #626's previously declared exploratory limits: 1 arcsecond per angular position, 1e-9 AU range, 0.1 arcsecond/day per angular rate and 5e-10 AU/day radial rate. Inspect direct Q20 separately at 0.001 km/s and report failures. Shared DE441, model differences, TT/TDB approximation and finite-difference limitations remain explicit; no claim of independent physical accuracy.
