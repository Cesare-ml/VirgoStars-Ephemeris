# USNO ΔT source-error provenance — 2026-11-18

The optional, caller-supplied USNO tables provide ΔT = TT−UT1 in seconds. They include non-prediction entries (some are historical reconstructions) and, if supplied, predictions. Nothing is downloaded or bundled, and no default source or UTC/local-time interpretation is introduced.

A previous implementation could attach one endpoint's source-reported error to an interpolation even when the other endpoint had no reported error. The corrected implementation retains an error between points only when **both** endpoints have one. At an exact point its own value is retained. Negative, nonfinite or malformed reported errors fail parsing; a missing prediction error remains unknown. ΔT values, interpolation and source-kind precedence are unchanged. This behavior changes the public optional `uncertainty_seconds` field for mixed-known/unknown intervals: consumers must handle `None`.

Source-reported errors do not by themselves define a confidence level or bound interpolation error. `Measured` is a legacy non-prediction label, not a claim that historical reconstructions are direct atomic-clock observations. Predictions remain labelled, may be dated, and are not silently substituted outside coverage. Historic decimal-year dates use the existing 365.25-day mapping, which differs from Gregorian year fractions. The input table's UT dates are interpreted by this code as UT1; the underlying monthly publication uses UTC, and that difference is not separately bounded here.

The focused correction and tests were recovered from branch `codex/de441-deltat-models-evaluation-20261118` commit `c2eccd5`; its broader model evaluation is not included here. Synthetic tests exercise missing, malformed and negative errors, exact points and transitions. An opt-in local test also parsed the already available USNO snapshot. Neither check validates all future snapshots, establishes statistical confidence, or independently measures historical Earth rotation.
