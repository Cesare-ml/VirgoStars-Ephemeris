# Classic JPL DE441 reader

`jpl-de441.mjs` reads the classic little-endian JPL DE441 binary, including the
`de441.eph` file distributed with Astrodienst's JPL files. It does not read
Astrodienst's compressed `.se1` files or NAIF SPK (`.bsp`) kernels. The data
file remains external and must be supplied by the caller. Node.js 22 or later
is required; no package installation is needed.

```js
import { openDe441 } from './src/jpl-de441.mjs';

const ephemeris = openDe441('D:/path/to/de441.eph');
try {
  const earth = ephemeris.state('earth', 2451545.0);
  console.log(earth.position, earth.velocity);
} finally {
  ephemeris.close();
}
```

Input dates are Julian dates on the **TDB** time scale, not UTC. The state is
geometric and expressed in equatorial ICRF coordinates; `position` is in km
and `velocity` in km/day. Bodies are relative to the solar-system barycenter,
except `moonGeocentric`, which is relative to Earth's center. Supported names
are `solarSystemBarycenter`, `sun`, `mercury`, `venus`, `earth`, `moon`,
`earthMoonBarycenter`, `moonGeocentric`, `marsBarycenter`, `jupiterBarycenter`,
`saturnBarycenter`, `uranusBarycenter`, `neptuneBarycenter`, and
`plutoBarycenter`. In particular, the outer-planet series represent system
barycenters, not the centers of the planets themselves.

`coverage.start` and `coverage.end` are inclusive Julian dates read from the
binary header. For the local copy inspected on 2026-11-09, they are
-3027215.5 and 7930192.5; those binary header values take precedence over the
human-readable title in the file. This does not convert civil time, apply
light-time, aberration, deflection, precession, nutation, topocentric
corrections, or calculate zodiac positions. It is a foundation for those
subsequent stages, not a complete astrological ephemeris API.

Run the self-contained tests with `node --test test/jpl-de441.test.mjs`. To
also exercise the real external file, set `DE441_PATH` to its path before
running the same command. The synthetic tests check known polynomials and
their derivatives; the external-file checks exercise Earth/Moon relationships
and coverage boundaries. Independent numerical comparison with JPL reference
vectors is still needed before claiming accuracy or production readiness.

Sources: [JPL ephemeris formats](https://ssd.jpl.nasa.gov/planets/eph_export.html),
[JPL-compatible binary header](https://www.imcce.fr/content/medias/recherche/equipes/asd/inpop/inpop_file_format_2_0.pdf),
[Astrodienst JPL file distribution](https://www.astro.com/swisseph-download/jplfiles/).
